Overview
This repository contains my Power BI projects showcasing skills in data cleaning, visualization, and storytelling. Each project demonstrates how raw data can be transformed into actionable insights for business decision-making.

Projects Included
Recruitment Analytics Dashboard

Dataset: Candidate pipeline and hiring metrics

Key Features: Time-to-hire analysis, source effectiveness, recruiter performance tracking

Insights: Identified bottlenecks in hiring process and improved reporting efficiency

Sales Performance Dashboard

Dataset: Product sales and customer feedback

Key Features: Trend analysis, customer satisfaction metrics, revenue breakdown

Insights: Highlighted top-performing products and areas for operational improvement

Rainfall & Crop Yield Analysis (Academic Project)

Dataset: Rainfall records and crop yield statistics

Key Features: Line charts, scatter plots, seasonal aggregations

Insights: Correlation between monsoon rainfall and agricultural yield
